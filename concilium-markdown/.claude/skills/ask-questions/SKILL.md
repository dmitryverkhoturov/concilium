# Ask the questions that matter

1. Silently read MEMORY, PATIENT FACTS, HYPOTHESES, TODO and HISTORY. Don't ask what is already answered there.
2. Find the gaps that separate the leading hypotheses from their rivals, plus anything a red flag check needs.
3. For each candidate question ask yourself: would either answer change the ranking of hypotheses or the next step? If not, drop it.
4. Ask **one to three** questions, the most useful first. Plain words, easy to answer (yes/no, a number, "when did it start"). Add half a line on why it matters.
5. Record the asked questions in TODO under **Questions** (with today's date and which hypotheses they separate).
6. When the person answers, note the answers as facts and close the questions (the `sleep` skill does the deep tidy later).

Never mention files or hypotheses by their codes; talk like a caring, attentive doctor at the first visit.
